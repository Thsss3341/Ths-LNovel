# Ths-LNovel

[English](README.md) | **简体中文**

适用于 [Nekori](https://github.com/Yuneko-dev/Nekori)、[LNReader](https://github.com/LNReader/lnreader)
及其他可运行 LNReader 插件的 App 的中文轻小说和网络小说插件：

| 插件 | 网站 | 重点 |
|------|------|------|
| **轻小说文库**（wenku8） | [wenku8.net](https://www.wenku8.net) | 日本轻小说；排行榜和完结全本列表，按卷分章，方便 MyAnimeList（MAL）追踪 |
| **嗶哩輕小說(繁體)**（linovelib） | [tw.linovelib.com](https://tw.linovelib.com) | 繁体中文轻小说；章节顺序正确，恢复书名搜索，方便 MAL 追踪 |
| **爱下电子书**（ixdzs8） | [ixdzs8.com](https://ixdzs8.com) | 中文网络小说（起点等）；书最多，可按分类、状态和字数筛选 |
| **全本小说网**（quanben） | [quanben.io](https://www.quanben.io) | 中文网络小说，多为完本 |
| **小說543**（novel543） | [novel543.com](https://www.novel543.com) | 繁体中文网络小说，部分作品比其他网站更新得更多 |
| **番茄小说**（fanqie） | [fanqienovel.com](https://fanqienovel.com) | 热门新网络小说，有分类排行榜。没有 SVIP 时每本书只能读前几章 |

> [!NOTE]
> 这是个人项目，主要供自己阅读使用。网站改版时插件可能失效，修复视个人时间而定。大部分代码在 AI（Claude Code）协助下编写，并由我本人在设备上测试。

## 安装

1. 把本仓库加入 App：
   - **Nekori：** 进入 **更多 → 设置 → 浏览 → Novel extension repos**，点 **添加**，粘贴下面的网址。
   - **LNReader：** 进入 **浏览 → 仓库（Repositories）**，点 **添加**，粘贴下面的网址。

   ```
   https://raw.githubusercontent.com/Thsss3341/Ths-LNovel/plugins/v1.0.0/.dist/plugins.min.json
   ```

2. 在 App 的插件列表（中文）中找到并安装需要的插件。
3. **轻小说文库**和**小說543**需要先在插件的 WebView（地球图标）中打开一次，通过网站的 Cloudflare 验证。轻小说文库还需要在那里登录，见[轻小说文库（wenku8）](#轻小说文库wenku8)。

linovelib、ixdzs8、quanben 和 novel543 插件使用自己的 ID，可以与社区仓库中同一网站的插件同时安装。

## 插件

### 轻小说文库（wenku8）

翻译成简体中文的日本轻小说。

- **需要 wenku8 账号。** wenku8 现在会把未登录的访客转到登录页，而且网站有 Cloudflare 保护。在插件的 WebView 中通过 Cloudflare 验证并登录 wenku8，插件会沿用这个登录。
- **浏览**网站的分类和排行：热门轻小说、动画化作品、今日更新、新书一览、**完结全本**、轻小说列表，以及排行榜、推荐榜、总收藏榜和字数排行。
- **按卷分章**，附插图。
- **用简体中文搜索**（例如「无职转生」），网站的书名都是简体。wenku8 每 5 秒只允许搜索一次。
- **方便 MAL 追踪。** 见[用 MyAnimeList 追踪](#用-myanimelist-追踪)。
- **不会超过网站的访问限制。** 加载太快会被封锁几分钟（Cloudflare「Error 1015」），所以插件每次请求间隔约 3 秒。批量下载章节会比较慢（每分钟约 20 章），但不会被封。
- 因版权问题被网站下架的小说可以打开，简介中会注明，但没有章节。

### 嗶哩輕小說(繁體)（linovelib）

繁体中文轻小说。

- **章节顺序正确。** 网站会把每章第 20 段之后的段落打乱，只在浏览器中排回原来的顺序。插件也会做同样的还原。
- **恢复书名搜索。** 网站取消了站内搜索，所以插件改为搜索每天重建的全站书目。可以用繁体、简体或作者名搜索：「史莱姆」和「史萊姆」都能找到《關於我轉生變成史萊姆這檔事》。输入小说网址或编号（例如 `https://tw.linovelib.com/novel/3095.html` 或 `3095`）可直接打开，书目重建后才新增的小说也可以。
- **浏览**排行榜、**完結全本**，或按 **狀態**（例如已經完本）、**動畫化**、**類型** 和 **字數** 筛选全站书目，并按所选排行排序。
- **找回隐藏的章节。** 部分章节在目录中没有链接，插件会通过上一章找到它们。
- **方便 MAL 追踪。** 见[用 MyAnimeList 追踪](#用-myanimelist-追踪)。

### 爱下电子书（ixdzs8）

中文网络小说（起点等），是这里几个网络小说来源中书最多的。

- **浏览**热门排行、全本完结和最近更新，或选 **分类**，再按 **状态**（连载中／已完结）、**排序**（最新／最热）和 **字数** 筛选。
- **自动通过网站自己的安全验证。**
- **未完成的章节。** 部分书最新的章节只是占位内容（「手打中！请稍后刷新！」）。这些章节会显示错误，而不会被保存，之后再试即可。

### 全本小说网（quanben）

中文网络小说，书不多，但多为完本。

- **浏览**首页推荐或选 **分类**。
- **章节列表完整。** 网站自己的目录会漏掉一些章节，插件会补上（命名为「第N章」）。
- **自动重试。** 网站经常断开连接，插件每个请求最多会试三次。

### 小說543（novel543）

繁体中文网络小说。部分作品比其他网站更新得更多，例如天命反派的《玄幻：我！天命大反派》，到约第 1,490 章。

- **有 Cloudflare 保护。** 先在插件的 WebView 中打开一次通过验证；插件提示验证过期时再打开一次。
- **用书名搜索**会触发比浏览更严格的 Cloudflare 验证。如果失败，改用小说网址或 10 位数编号搜索，例如 `0520109072`。
- **浏览**首頁推薦或書庫，按 **分類**、**狀態**（連載／完結）和 **頻道**（男生／女生）筛选。
- **长章节**在网站上分成几页，插件会合并成一章。
- 网站无法显示的章节（「章節錯誤」）会显示错误，而不是空白页。

### 番茄小说（fanqie）

字节跳动的网络小说平台，有许多当下热门的中文网络小说。

- **没有 SVIP 只能读前几章。** 番茄小说在自家 App 中免费，但网页版每本书只提供前几章（通常 10 章）的全文，其余章节需要番茄 SVIP 会员。这些章节会显示错误，而不会保存不完整的内容。如果有 SVIP，在插件的 WebView 中登录即可阅读。
- **文字正常显示。** 网页版用打乱的字体显示常用字，插件会把它们还原成正常文字。
- **浏览**书库，按 **读者**（男生／女生）、**分类**、**状态**、**字数** 和 **排序**（最热／最新／字数）筛选，或按 **榜单分类** 浏览网站的阅读榜和新书榜。
- **用书名搜索**需要通过网站的滑块验证。如果失败，在插件的 WebView 中打开网站搜索一次，然后重试。用书的网址或书号搜索一定可以，例如 `https://fanqienovel.com/page/7069948840148732967` 或 `7069948840148732967`。

> [!TIP]
> 同一个书名在不同网站上可能是不同的书，请核对作者。例如全本小说网的「玄幻：我！天命大反派」作者是罗昼，而爱下电子书和小說543 的是天命反派。

## 用 MyAnimeList 追踪

本节适用于**轻小说文库**和**嗶哩輕小說(繁體)**。MyAnimeList 的搜索找不到中文书名，所以打开小说时，插件会查找它的 MAL 条目，并加在简介最上面：

```
MAL：Mushoku Tensei: Isekai Ittara Honki Dasu
id:70261
日文名：無職転生 ～異世界行ったら本気だす～
英文名：Mushoku Tensei: Jobless Reincarnation
```

**追踪小说：** 长按 `id:70261` 那一行，复制后粘贴到 MAL 追踪的搜索框。搜索 `id:` 加数字会直接找到那个条目。

**如何匹配：** 插件先用中文书名在 [Bangumi](https://bgm.tv) 搜索，取得日文原名，再用日文原名在 [AniList](https://anilist.co) 搜索 MAL ID 以及罗马音和英文书名。linovelib 使用网站简体版的书名，因为 Bangumi 的中文名是简体。

- **精确匹配：** 书名完全相同。
- **可能匹配：** 书名只是相似（翻译不同），但作者相同，或书名只差几个字，例如「败北女角太多了」和 Bangumi 的「败犬女主太多了」。会标注 **⚠ 非精确匹配，可能不准确**（linovelib 中为 **⚠ 非精確匹配，可能不準確**），追踪前请先核对条目。
- **没有匹配：** 简介不变。通常是译名与 Bangumi 差太多，或该小说不在 MAL 上。
- **只有 Bangumi：** AniList 没有 MAL ID 时，简介显示 `MAL：未找到` 和日文原名，仍可用日文原名在 MAL 搜索。

**小提示：**

- 第一次查找需要几秒。精确匹配会一直记住；可能匹配和没找到的，一星期后会重新查找。
- 书架中已有的小说，在小说页面下拉刷新后就会出现 MAL 资料。
- 要关闭查找，打开插件设置，关闭 **简介中显示MAL标题和ID**（linovelib 中为 **簡介中顯示MAL標題和ID**）。

## 更新

有新版本时，App 的插件列表会显示更新。更新插件不会影响书架。

## 常见问题

**显示「Cloudflare 验证已过期…」或「Cloudflare 驗證已過期…」**<br>
网站的 Cloudflare 验证过期了。打开插件的 WebView（地球图标），通常会自动通过验证，然后返回重试。

**轻小说文库：显示「需要登录…」**<br>
wenku8 的登录已过期，请在插件的 WebView 中重新登录。

**轻小说文库：显示「请求过快…」或 Cloudflare「Error 1015」**<br>
加载太快被 wenku8 暂时封锁了。等待提示的时间，在此之前插件不会发送任何请求。

**轻小说文库：显示「轻小说文库限制两次搜索间隔不少于 5 秒…」**<br>
wenku8 每 5 秒只允许搜索一次，稍等再搜索。

**轻小说文库：搜索没有结果**<br>
请用简体书名搜索（「无职转生」，而不是「無職轉生」）。

**轻小说文库：显示「Unable to load novel」（LNReader）或简介注明因版权问题**<br>
这部小说因版权问题被 wenku8 下架，没有章节。

**嗶哩輕小說：显示「嗶哩輕小說只回傳了部分章節內容…」**<br>
网站把你当成机器人，只给了部分章节。在插件的 WebView 中打开网站首页，然后重试。

**嗶哩輕小說：显示「無法下載搜尋索引…」**<br>
无法下载搜索书目。稍后再试，或用小说网址或编号搜索。

**爱下电子书：显示「爱下电子书还没有这一章的内容（手打中）…」**<br>
网站还没有这一章的内容。稍后再试，或到其他网站阅读。

**爱下电子书：显示「爱下电子书的安全验证没有通过…」**<br>
在插件的 WebView 中打开该章节，然后返回重试。

**全本小说网：页面加载失败**<br>
网站偶尔会断开连接，下拉刷新重试即可。

**小說543：显示「小說543 暫時沒有這一章的內容（章節錯誤）…」**<br>
网站暂时无法显示这一章。稍后再试，或到其他网站阅读。

**小說543：书名搜索显示 Cloudflare 验证提示**<br>
在插件的 WebView 中打开网站并搜索一次，或改用小说网址或编号搜索。

**番茄小说：显示「番茄小说网页版只免费提供前几章…」**<br>
网页版只向 SVIP 会员提供这一章。在插件的 WebView 中登录 SVIP 账号，或在番茄小说 App 中免费阅读。

**番茄小说：显示「番茄小说的搜索需要先通过滑块验证…」**<br>
在插件的 WebView 中打开网站搜索一次（如果出现滑块就完成验证），然后重试；或改用书的网址或书号搜索。

**无法加入仓库**<br>
确认网址与[安装](#安装)中的完全一致。

**其他问题**<br>
请到 [Issues](https://github.com/Thsss3341/Ths-LNovel/issues) 回报，附上插件、小说名称和发生的情况。
